PRODUCTION READY CHECKLIST

Jadikan evidence sebagai source of truth.

Dashboard lokal untuk memetakan readiness aplikasi, menyimpan lokasi dokumen, mengaudit repository, dan meminta AI agent membantu menutup gap dengan bukti yang dapat direview.

Buka dashboard →GitHub repository ↗Download document index JSON

Platform ini bukan sekadar checklist. Ia menghubungkan tiap requirement dengan owner, artefak, evidence, dan lokasi dokumen kanonis. Agent boleh menemukan kandidat evidence atau membuat draft, tetapi manusia tetap mereview sebelum item dinyatakan selesai.

1. Jalankan di local

Butuh Node.js 18 atau lebih baru.

git clone https://github.com/sammyjason39/production-ready-checklist.git
cd production-ready-checklist
npm install
npm run dev

Workspace, status, dan imported index disimpan pada browser melalui localStorage.

2. Petakan proyek

Atur tipe produk, tier risiko, AI/Agent, dan public web. Tambahkan anggota tim beserta skill dan posisi mereka di Projects & team.

Mulai dari Application Profile, owner, dan risk tier. Kecepatan build tidak menggantikan keputusan ini.

3. Simpan lokasi dokumen di Document Index

Agent atau tim menyimpan path dan URL kanonis di <target-repo>/.production-ready/documents.json.

{
  "schemaVersion": "1.0",
  "documents": [{
    "checklistId": "DES-001",
    "artifactCode": "PRO-004",
    "title": "PRD v1",
    "type": "markdown",
    "location": { "type": "repository", "path": "docs/product/prd.md" }
  }]
}

Checklist → Document Index → Import index. Pilih root folder repository satu kali untuk membuka file lokal. Markdown, PDF, dan DOCX dibaca lokal; URL Jira/ClickUp/Notion/Drive dibuka di browser.

4. Install skills

Salin atau symlink kedua folder ini ke skills directory agent:

skills/production-readiness-scan/
skills/production-readiness-evidence/

Format SKILL.md dapat dipakai Codex, Claude, Hermes, atau agent lain yang mendukung convention tersebut.

Scan skill ↗Evidence skill ↗

5. Scan repository

Agent menjalankan scanner tanpa mengirim source code keluar dari mesin.

node scripts/scan-repository.mjs \
  --root /absolute/path/to/target-repository

Hasil ada di .production-ready/audit.json. Di dashboard: Checklist → Local agent workflow → Import scan.

Scan hanya memberi candidate evidence; ia tidak otomatis memberi status Selesai.

6. Dokumentasi online melalui MCP

Hubungkan sumber yang diotorisasi.

Agent memakai MCP untuk Jira, ClickUp, Notion, Drive, atau sistem lain hanya pada project/folder/space yang user izinkan.

Tulis index, bukan credential.

Agent menyimpan judul, URL/path kanonis, status, tag, dan ringkasan faktual pada documents.json. Jangan commit token atau isi dokumen privat yang tidak diperlukan.

Review dan iterasi.

Import document index dan audit report, buka evidence, tetapkan owner, gunakan Copy prompt untuk membuat draft, lalu review dan scan ulang.

Alur singkat

Repository / MCP docs → documents.json → dashboard Document Index
Repository + documents.json → scan-repository.mjs → audit.json → dashboard checklist
Checklist gap → Copy prompt / Agent gap plan → draft artefak → review owner → evidence
README lengkap ↗Agent workflow ↗
