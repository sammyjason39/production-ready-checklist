# Technical artifact templates

These files are fill-in-ready documents for a real release. Copy a file into the target repository, replace every `[placeholder]`, and link the finished document in `.production-ready/documents.json`.

They are intentionally templates, not fabricated evidence. A release is only ready when the named owner has reviewed the actual command output, dashboards, approvals, and links recorded in the document.

Available templates:

- [Unit Test Plan](unit-test-plan.md)
- [Integration Test Plan](integration-test-plan.md)
- [Database Migration Plan](database-migration-plan.md)
- [Deployment Plan](deployment-plan.md)
- [Rollback Plan](rollback-plan.md)
- [Test Evidence and Release Sign-off](test-evidence-release-signoff.md)
